# Результаты k6 baseline: so3 cluster, 3 ноды

Этот отчет фиксирует исторический исходный уровень трёхнодового прототипа. Абсолютные значения пропускной способности
и задержек не являются продуктовым заявлением и не используются для сравнения с промышленными S3-совместимыми системами.
Основное назначение этих данных — воспроизводимость и дальнейшая нормализация сценариев с отказами, конфликтами
и восстановлением.

Последняя локальная проверка k6: 2026-05-17 на macOS, один физический хост c M4 Pro.

## Команда

```bash
BACKEND_START_TIMEOUT_SECS=30 python scripts/k6/run-backend-benchmark.py --backend so3-cluster --runs 30 --outdir /tmp/so3-cluster-k6-clean-30-json
```

## Методика

Backend: `target/release/so3`.
Режим: 3 локальных процесса `so3`, у каждого отдельная директория данных и фиксированный `SO3_NODE_ID`. S3 endpoint
опубликован через первую ноду (`127.0.0.1:3000`); остальные ноды слушали S3 на `127.0.0.1:3001` и `127.0.0.1:3002`,
RPC — на `127.0.0.1:4000..4002`. Для каждой ноды `SO3_CLUSTER_PEERS` содержал две остальные ноды.
Конфигурация k6: 10 VU, 30 запусков по 30 секунд, объекты по 64 байта. Каждая итерация выполняет S3-операции
`putObject -> getObject -> HEAD Object -> deleteObject`.

Каждый k6-запуск был чистым: runner перед каждым прогоном запускал новый кластер из трёх процессов с новыми временными
директориями данных, после прогона останавливал процессы и удалял директории данных.

Статистика ниже рассчитана по 30 независимым запускам. `σ` — стандартное отклонение, `стандартная ошибка` и `95% ДИ` —
оценки неопределённости среднего; `коэф. вариации` — относительный разброс. Дисперсия считается как выборочная (`n - 1`
в знаменателе).

- Пропускная способность кластера: 81.2452 req/s, это 56.6% от однонодового результата (-43.4%).

- Средний `GET` вырос с 59.46 до 96.58 ms (1.62×).
- Средний `HEAD` вырос с 62.23 до 98.38 ms (1.58×).
- Средний `DELETE` вырос с 69.48 до 121.64 ms (1.75×).
- Все три процесса запускались на одном физическом хосте, поэтому это локальный многопроцессный тест, а не
  многохостовой сетевой.
